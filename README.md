## 🚀 Projects

### Optha — clinical management platform for ophthalmology practices `private repo`
Co-founder, one of four partners. Multi-module Spring Boot backend with hexagonal
architecture, OAuth2/JWT via Keycloak, an OCR pipeline for handwritten clinical notes and
PDF report generation. Angular 20 frontend, fully containerised.

`Java 21` `Spring Boot 3.3` `PostgreSQL` `Flyway` `Keycloak` `Angular 20` `Docker` `Testcontainers` `ArchUnit`

### [ResQFood](https://github.com/maraujofeltrin/ResQFood) — gastronomic surplus rescue platform
Commerces publish surplus food packs at reduced prices; clients search, reserve, bid and
pick up. Auction-based dynamic pricing, code-based pickup, two-layer authorization (role
rules plus resource-ownership checks with SpEL), i18n and email verification.
Team of five for an ITBA course — I coordinated the work and reviewed technical decisions
before integration.

`Java 21` `Spring MVC 5.3` `Spring Security` `Hibernate` `PostgreSQL` `Flyway` `JSP/JSTL` `Docker Compose` `JUnit 5` `Mockito`

### [TPE-protos](https://github.com/maraujofeltrin/TPE-Protos) — SOCKS5 proxy server and management client
`socks5d`: a SOCKS5 proxy in C with user authentication and DNS resolution performed by
the proxy. `socks5_client`: a management client for users, metrics, logs and runtime
configuration.

`C` `Sockets` `SOCKS5` `Linux`

### [Visual Secret Sharing](https://github.com/maraujofeltrin/Cripto-Seguridad-TP) — Wu & Lo secret sharing for BMP images
C implementation of the Wu & Lo visual secret sharing scheme for 8-bit BMP images, built
for a cryptography and security course.

`C` `Cryptography` `Image processing`

### [x86-64 Operating System](https://github.com/santinopepe/TP2_SO) — freestanding kernel in C and NASM
Round-robin scheduler with dynamic priorities, two interchangeable memory managers
(bitmap and buddy) behind a single interface, 41 syscalls, semaphores and pipes with real
blocking, and a userland shell with pipes and background jobs. Runs on QEMU.
Team of three; the repository is hosted on a teammate's account.

`C` `x86-64 Assembly (NASM)` `QEMU`
